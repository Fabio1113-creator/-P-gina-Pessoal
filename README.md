# Página Pessoal — Fábio Souza da Cruz

## 📌 Sobre o projeto

Este projeto foi desenvolvido como uma página pessoal utilizando **HTML5 e CSS3**. A página apresenta informações sobre mim, meus interesses, meus objetivos e as tecnologias que já conheço ou pretendo aprender.

O projeto faz parte de uma atividade acadêmica voltada ao desenvolvimento web, com o objetivo de praticar a criação de páginas, a organização do código e o uso de ferramentas de versionamento.

---

## 🎯 Objetivo

O objetivo principal deste projeto é criar uma página pessoal simples, organizada e responsiva, capaz de apresentar:

- Meu nome e uma breve apresentação;
- Meus interesses na área de tecnologia;
- Meus objetivos pessoais e profissionais;
- As tecnologias e conhecimentos que já possuo;
- Tecnologias e assuntos que desejo aprender;
- Informações sobre o desenvolvimento do próprio projeto.

Além do desenvolvimento da página, o projeto utiliza **Git e GitHub** para registrar a evolução do trabalho e armazenar o código em um repositório remoto.

---

## 🖥️ Sobre a página

A página foi organizada em diferentes seções para facilitar a navegação e a apresentação das informações.

### Início

Apresenta meu nome, uma breve introdução e um botão para acessar a seção de apresentação.

### Sobre Mim

Contém uma apresentação pessoal e informações sobre meu interesse pela área de tecnologia e desenvolvimento web.

### Interesses e Objetivos

Apresenta alguns dos meus principais interesses, como tecnologia, programação, desenvolvimento web e desenvolvimento de sistemas de automação e robótica.

### Habilidades e Tecnologias

A seção apresenta duas categorias:

**Conhecimentos atuais:**
- HTML
- CSS
- Git
- JavaScript
- GitHub
- SQL

**Conhecimentos que desejo desenvolver:**
- OEE
- Python
- KRL
- URScript
- Indústria 4.0
- React

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — utilizado para criar a estrutura e o conteúdo da página.
- **CSS3** — utilizado para definir o visual, layout, cores, espaçamentos, efeitos e responsividade.
- **Git** — utilizado para controlar as versões e registrar a evolução do projeto.
- **GitHub** — utilizado para armazenar e compartilhar o repositório.
- **Visual Studio Code** — utilizado como ambiente de desenvolvimento.
- **VS Code com auxílio de IA** — utilizado como apoio na criação e organização de textos e na estruturação do projeto. A ferramenta foi utilizada como suporte ao desenvolvimento, enquanto o código e o projeto foram revisados e organizados no VS Code.

## 🎨 Características visuais

O projeto utiliza um estilo moderno e simples, com:

- Cabeçalho fixo;
- Menu de navegação;
- Seção inicial de destaque;
- Cards para apresentação dos interesses;
- Organização das habilidades em categorias;
- Botões e efeitos de interação;


---

## 🔄 Versionamento

Durante o desenvolvimento, o projeto é versionado utilizando Git.

As alterações são registradas por meio de commits e posteriormente enviadas para um repositório remoto no GitHub. Dessa forma, é possível acompanhar a evolução do projeto durante as etapas da atividade.

Exemplo de comando utilizado:

```bash
git add .
git commit -m "Adiciona README do projeto"
git push
```
